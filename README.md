# kasane

Two kitty terminal color themes designed for calm reading. Named for _kasane no irome_ (重ねの色目), the traditional Japanese practice of pairing kimono layers so that carefully chosen colors show at the sleeves and collar. Each layer is individually restrained, and the combination creates quiet depth without noise.

## Accessibility

These themes were made by someone who is color-blind and has dyslexia. The problem with most beautiful themes is that one or two accents read identically for color-deficient eyes, or the palette is harmonious enough that the eyes lock in to it, worsening reading difficulty and forcing a rotation to something new. Ferra, gruvbox, meliora, and ayu are all in regular rotation for this reason. Each is nearly right. Each eventually tires in a specific way.

kasane tries to thread that needle. Every accent sits in the middle ground: nothing bright enough to demand attention or cause eye strain, nothing pale enough to vanish, and no two adjacent tones close enough to collapse into each other. The foreground is warm parchment against a near-black ground. Strong contrast, without the harshness of white on black.

The goal is a terminal environment as calm as sitting on tatami in a kimono with a cup of tea, where the tools stay quiet and the text stays readable.

## Themes

### shibui (渋い)

Named for the Japanese aesthetic concept of subdued, unobtrusive beauty. A cool dark blue-black ground with all six accents desaturated and held at the edge of legibility. Nothing announces itself.

```sh
include /path/to/kasane/themes/shibui.conf
```

### obi (帯)

Named for the sash of a kimono: darker and plainer than the cloth, the thing that holds everything together without drawing the eye. Near-black ground with only a trace of cool. The six accents cover the full hue spread, from coral to cherry blossom to sage and water, each held at the same restraint.

```sh
include /path/to/kasane/themes/obi.conf
```

## Variants

Each theme ships in three forms:

| File                                                       | Use                                                                                                      |
| ---------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| `shibui.conf` / `obi.conf`                                 | Main dark background                                                                                     |
| `shibui-raised.conf` / `obi-raised.conf`                   | Lighter background for elevated panels                                                                   |
| `shibui-gamma-corrected.conf` / `obi-gamma-corrected.conf` | Pre-shifted for wide-gamut displays so kitty renders the same perceived values as an ICC-managed browser |

## Usage

```sh
# Preview live
kitty --config "$HOME/.config/kitty/kitty.conf" --config themes/obi.conf

# Permanent — add to kitty.conf
include /path/to/kasane/themes/obi.conf
```

## Layout

- `themes/` — the six `.conf` files
- `docs/` — palette study site, generated by `scripts/build_palette_docs.py`
- `scripts/` — `gen_gamma.py` regenerates gamma-corrected files after editing a raw theme, `build_palette_docs.py` regenerates the docs site

## Influences

The palette was shaped by years of rotating between ferra, gruvbox, meliora, and ayu. kasane is not a replacement for any of them. It occupies a specific, narrow niche shaped by accessibility constraints and a particular aesthetic preference.

The visual references are a calligraphy scroll (sumi ink, seal red, gilt), a kimono (cool dark cloth and its sash), and a tatami mat (sage-olive weave). Colors are not literal pixel samples from those sources. They represent the intent: dark, muted, and considered.
